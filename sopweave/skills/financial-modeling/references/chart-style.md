# 财务图表风格规范（Chart Style）

> 借鉴 figures4papers（Yale 刘晨论文配图仓库）的「出版级绘图设计理论」，结合
> ECharts 渲染与财务分析场景固化的 10 条复现规则。生成图表时遵循本规范，
> 使 24 类模板收敛为统一、专业、可交付的「财务图表语言」。

---

## 1) 字体与字号（Typography）

- **字体栈**：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`（前端默认，
  中英文混排场景优先；不额外指定衬线体）。
- **字号层级**：
  - 标题：14px（容器标题栏已展示表名，图表内不重复大标题）
  - 轴标签 / 图例：12px 起
  - 数据点标注：10px（`label.fontSize: 10`）
  - 缩放提示/说明行：10px（浅灰）
- **数据标注**：数值直接显示在数据点/柱顶（`label.show: true, position: "top"`），
  颜色 `#52525b` —— 财务读者要「一眼看到数字」，不依赖 hover。

## 2) 配色体系（Palette）

- **默认 8 色主序**（多系列蓝橙主色 + 辅助色）：
  `#2563eb 蓝 / #f97316 橙 / #0d9488 青 / #db2777 品红 / #7c3aed 紫 / #059669 绿 / #d97706 深橙 / #4f46e5 靛蓝`
- **同色系深浅渐变**（color_scheme = "blues" 等）：首色为主色，由深到浅 5 档，
  语义 = 「同一口径的不同程度/层级」，深浅间距需肉眼可辨（明度差 ≥ 15%）。
- **语义色（固定，不随主题变）**：
  - 盈利/正数 → 绿 `#059669`；亏损/负数 → 红 `#dc2626`
  - 目标/阈值线 → 红虚线 `#dc2626`；预测 → 深灰虚线
  - 高亮/当前 → 蓝 `#2563eb`
- **禁止**：与语义冲突的随机色（如把亏损画成蓝色）；相邻系列明度过近导致难区分。

## 3) 轴线与网格（Axes）

- **极简轴线**：默认隐藏 top/right 轴线；只留左/下轴线（`#d4d4d8` 细线）。
- **网格淡化**：网格线 `#f4f4f5`（近白），不干扰数据；数值轴保留，类别轴可去。
- **坐标轴留白**：y 轴上限 ≈ 数据最大值 + 8~15% 余量（柱顶标注不贴边）；
  柱状图 x 轴类别间留 `barGap` 默认，避免柱子贴死。

## 4) 布局与构成（Layout）

- **单图表容器**：高 288px（`h-72`），宽自适应（max-w 容器内 100%）。
- **多面板**：优先独立图表卡片（每个图表 = 一个卡片，含标题栏 + 数据表折叠），
  不强行拼大图；需要对比时用并排多卡片（用户可分别下载）。
- **图例**：多系列时置于底部（`legend.bottom: 0`），单系列不显示图例。
- **留白**：图表边距默认，标注/图例不贴容器边（padding 8px+）。

## 5) 柱状编码（Bar Encoding）

- 对比/排名 → `bar`（分组柱状，多系列并排）；单系列 → `bar-simple`。
- 盈亏正负 → `bar-negative`（横向，绿正红负）；量+率 → `bar-line`（柱+线双轴）；多年+趋势 → `bar-fancy`。
- **数据标签**：柱顶显示数值；千分位格式化（财务金额必须千分位）。

## 6) 折线编码（Trend Encoding）

- 趋势/多系列对比 → `line`（默认多维折线，自动标极值/平均线）；单系列 → `line-simple`。
- 跨期同期对比（双 x 轴）→ `line-multi-x`。
- 多系列趋势必须可区分：颜色不同 + 线型/符号辅助（单色打印安全）。

## 7) 占比/分布编码（Proportion & Distribution）

- 占比 → `pie`（默认环形 donut；多层 → `sunburst`/`nested`）。
- 分布 → `histogram` / `boxplot`（multi 多组对比）。
- 相关性 → `scatter`（regression 回归线 + R² 标注）或 `heatmap`（相关矩阵，discrete 离散）。

## 8) 财务专用模板（Finance-Specific）

- 敏感性排序 → `tornado`；差异桥接 → `waterfall`（预算差异逐项拆解）。
- 多维指标对比 → `radar`（杜邦五维，multi 多期/多主体）。
- 资金流向 → `sankey`；KPI 达成 → `gauge`（progress/stage）。
- 三变量空间关系 → `scatter3d`/`bar3d`（可旋转，L3）；散点+分箱联动 → `histogram-4grid`。

## 9) 打印与交付（Print & Delivery）

- **导出格式（2026-08-21 起仅两种）**：
  - **SVG**：2D 图矢量导出，文本可编辑、无损缩放 —— 论文/报告首选
  - **HTML**：保留交互/3D 旋转 —— 汇报/演示首选
  - ~~PNG~~：已移除（位图放大模糊、文本不可编辑）
- **3D 图限制（v6.9 更新）**：`scatter3d`/`bar3d`/`waterfall3d` 三个 3D 模板**已改由 Python(mplot3d)
  生成 PNG**（前端自动调 `/api/apps/finmod/py-chart`，AI 无需介入）。3D 图**不支持矢量导出**（无 SVG），
  仅 PNG；**图内不含数据大标题**（容器标题栏已展示表名），坐标轴标签（如 `时间（年）`/`财务指标`/`数值（%）`）
  保留以明示维度含义。走 Python 分支后不再依赖 echarts-gl/WebGL。
- **导出净化**：SVG/HTML 不含 slider 滑块条、tooltip 层（导出前隐藏交互控件）。
- 需打印灰度场景：优先用「浅→深」单色系（黑灰系）而非彩色（灰度下绿/蓝难区分）。

## 10) 复现规则（Reproduction Rules）

1. 先选复杂度档位（L1/L2/L3）→ 只从档内模板选型，禁止跨档。
2. 配色用默认 8 色序或同色系渐变；语义色（绿正/红负/蓝当前）固定不改。
3. 每个图表必须带 `data_table`（数据表折叠区）+ 数据口径说明（§6 协议）。
4. 数据点直接标注数值，千分位格式化；坐标轴留白 8~15%。
5. 多系列 → 底部图例；单系列 → 无图例。
6. 导出优先 SVG（矢量，2D）；**3D 图（scatter3d/bar3d/waterfall3d）仅 PNG**（Python 生成，无矢量）。
7. 图表是「结论载体」：一张图一个结论，禁止堆叠无关信息。

## 与 references 的关系

- `charts/<模板>.md`：单模板的数据结构/变体/选型建议（L2 按需读取）
- 本文件：全局风格/配色/标注/导出的统一规范（所有模板共用）
- AI 生成图表时：先读目标 `charts/<模板>.md` 定数据结构，再按本规范定
  配色/标注/导出 —— 风格一致性靠本文件收敛。
