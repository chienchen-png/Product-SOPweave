# 图表模板：funnel（漏斗图）

> **复杂度档位：L1 简单**（P6-①：单/双变量平面图，直观快速）

## 用途
展示流程各阶段的量级递减（转化/流失）。

## 典型场景
- 销售漏斗（线索 → 报价 → 签约 → 回款）
- 审批流程各环节数量
- 客户转化率

## 数据结构
```json
{
  "categories": ["线索", "报价", "签约", "回款"],
  "series": [
    { "name": "数量", "data": [1000, 600, 300, 150] }
  ]
}
```
- categories：漏斗各阶段（自上而下）
- data：各阶段数量（自动按比例宽度显示）

## 选型建议
- 阶段转化 → funnel
- 分类占比 → pie
- 阶段金额累计 → waterfall

## 变体清单（P5-②，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `funnel` / `funnel-simple` | 转化漏斗（默认） | 阶段转化/流失 |
| `funnel-compare` | 对比漏斗 | 两个漏斗并列（实际 vs 目标/去年） |

> 借鉴官方示例：funnel-basic / funnel-compare。

## 注意事项
- 各阶段为独立类别（非同一总体划分）
- 转化率可在 tooltip formatter 显示（option_overrides）
