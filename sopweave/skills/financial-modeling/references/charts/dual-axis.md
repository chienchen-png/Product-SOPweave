# 图表模板：dual-axis（双轴组合图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

两个量纲不同但相关的系列同图对比（左轴 + 右轴）。

## 典型场景
- 实际 vs 预算（双柱/柱线组合）（B2、D3）
- 量价双轴：销量（柱）+ 单价（线）
- 收入（柱）+ 毛利率（线）

## 数据结构
```json
{
  "categories": ["1月", "2月", "3月", "..."],
  "series": [
    { "name": "实际收入", "data": [120, 135, 128, "..."], "yAxisIndex": 0, "type": "bar" },
    { "name": "预算收入", "data": [130, 130, 130, "..."], "yAxisIndex": 0, "type": "bar" },
    { "name": "毛利率", "data": [32, 34, 33, "..."], "yAxisIndex": 1, "type": "line" }
  ]
}
```
- series[].yAxisIndex：0 = 左轴，1 = 右轴
- type：bar / line 可混搭

## 选型建议
- 两个不同单位系列 → dual-axis
- 同单位多系列 → line / bar
- 差异桥接 → waterfall

## 注意事项
- 双轴必须命名清楚（左/右轴名经 option_overrides）
- 两个轴刻度范围要合理（避免误导性对比）
- 系列 ≤ 4 个（太多双轴难读）
