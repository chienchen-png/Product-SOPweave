# 图表模板：line（折线图）

> **复杂度档位：L1 简单**（P6-①：单/双变量平面图，直观快速）

## 用途
展示时间序列趋势、多系列对比、跨期同期对比。财务最常用的图表。

## 典型场景
- 收入/费用月度趋势
- 同比/环比趋势（D4）
- 最高/最低区间对比（分组对比）
- 跨年同期对比（多x轴，2015/2016）

## 数据结构
```json
{
  "categories": ["2025-01", "2025-02", "2025-03", "..."],
  "series": [
    { "name": "实际收入", "data": [120, 135, 128, 130] },
    { "name": "预测收入", "data": [110, 120, 115, 122] }
  ]
}
```
- line-multi-x（多x轴）：`xCategories`（第一时段）+ `xCategories2`（第二时段）+ 系列 `xAxisIndex`（0/1）。

## 选型建议
- **趋势/时间序列** → line（默认多维分组对比，多系列 + 极值/平均线）
- **单系列基础** → line-simple
- **跨期同期对比** → line-multi-x（双 x 轴）
- **对比不同类别** → bar

## 变体清单（2026-08-23 按用户附件重构，template 传 `类型-变体` 名）

| 变体 | 图表 | 适用点 | 变量点 | 优势点 |
|------|------|--------|--------|--------|
| `line` | 多维折线图（分组对比） | 多系列趋势对比 | 时间 × N 数值系列 | 自动标出极值/平均线 |
| `line-simple` | 简单折线图 | 单系列趋势 | 时间 × 1 数值 | 最基础，可直接读点 |
| `line-multi-x` | 多x轴折线图 | 两时段同期对比 | 双时间轴 × 数值 | 同图看跨期差异 |

## 注意事项
- 双系列时开 legend；单位不同用 `bar-line` 或 `dual-axis`
- 数据 ≤ 200 点（SKILL.md 约束）
