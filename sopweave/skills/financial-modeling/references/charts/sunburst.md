# 图表模板：sunburst（旭日图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

多层嵌套占比展示（从外层到内层逐层细分）。

## 典型场景
- 收入多层结构：集团 → 事业部 → 产品线
- 成本层级构成
- 客户层级贡献

## 数据结构
```json
{
  "series": [
    {
      "name": "收入结构",
      "data": [
        { "name": "集团", "children": [
          { "name": "事业部A", "value": 500, "children": [
            { "name": "产品A1", "value": 300 },
            { "name": "产品A2", "value": 200 }
          ] },
          { "name": "事业部B", "value": 300 }
        ] }
      ]
    }
  ]
}
```
- 树形嵌套结构：children 递归；value 为叶节点数值

## 选型建议
- 多层占比 → sunburst
- 单层占比 → pie
- 多层对比 → bar（降维后分组对比）

## 注意事项
- 层级 ≤ 3 层（更深难读）
- 总节点数值 = 子节点之和（数据一致性）
