# 图表模板：error-bar（误差条/区间图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

展示预测/估计值的区间（均值 ± 上下界），适合预测置信区间、估计误差可视化。

## 典型场景
- 销售预测的置信区间（B3/G5 预测 ± 误差）
- 各月费用预测区间
- 估计值（均值）与波动范围

## 数据结构
```json
{
  "categories": ["1月", "2月", "3月"],
  "series": [
    { "name": "预测", "data": [
      [100, 90, 110],
      [120, 105, 135]
    ]}
  ]
}
```
- data 每项为三元组 `[value, low, high]`（value=均值，low=下界，high=上界）
- 也支持 `{value, low, high}` 对象形式

## 变体清单（P5-③，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `error-bar` / `error-bar-bar` | 误差条（默认） | 柱 + 上下误差须 |
| `error-bar-range` | 区间带 | 上下界折线 + 填充带（置信区间） |

> 借鉴官方示例：custom-error-bar / 区间带（two-value 面积）。

## 选型建议
- 点状预测（少量期间）→ error-bar
- 连续期间预测区间 → error-bar-range（带状更连续）
- 只想看均值趋势 → line

## 注意事项
- 数据 ≤ 200 点；low ≤ value ≤ high 需保证
- 区间过大时考虑对数轴
