# 图表模板：bar（柱状图）

> **复杂度档位：L1 简单**（P6-①：单/多变量平面图，直观快速）

## 用途
不同类别之间的数值对比、排名、结构分布。财务统计最基础最常用。

## 典型场景
- 部门/产品线收入对比（C4）
- 各月费用对比
- 三情景 NPV 对比（E4）
- 账龄区间分布（F2）

## 数据结构
```json
{
  "categories": ["产品A", "产品B", "产品C"],
  "series": [
    { "name": "收入", "data": [500, 320, 180] },
    { "name": "毛利", "data": [150, 120, 60] }
  ]
}
```
- bar-negative（正负条形）：series 含负值（如费用 -120），费用类 name 含「费用/成本」自动堆叠。
- bar-line（折线柱状）：量用 `type:"bar"`，率/趋势用 `type:"line"`（+ `yAxis0Name`/`yAxis1Name` 轴名）。
- bar-fancy（分组折线柱）：多系列柱（year）+ `type:"custom"` 的 trend 系列（data=[[x,y1,y2,y3],...]）。

## 选型建议
- **对比/排名** → bar（默认分组柱状，多系列并排）
- **单系列基础** → bar-simple
- **盈亏正负** → bar-negative（正绿负红，横向）
- **柱 + 率/趋势** → bar-line（柱看量、线看率，双 y 轴）
- **多年分组 + 整体趋势线** → bar-fancy

## 变体清单（2026-08-23 按用户附件重构，template 传 `类型-变体` 名）

| 变体 | 图表 | 适用点 | 变量点 | 优势点 |
|------|------|--------|--------|--------|
| `bar` | 分组柱状图 | 同类别多口径并排对比 | 1 类目 × N 数值系列 | 一眼对比多指标大小 |
| `bar-simple` | 简单柱状图 | 单系列类别对比/排名 | 1 类目 × 1 数值 | 最基础，直观 |
| `bar-negative` | 正负条形图 | 盈亏/现金流正负 | 1 类目 × 可正负差值 | 绿正红负，一目了然 |
| `bar-line` | 折线柱状图 | 量 + 率/趋势同图 | 1 类目 × (柱量 + 线率) | 柱看规模、线看比率 |
| `bar-fancy` | 分组折线柱状图 | 多年分组 + 趋势线 | N 年柱 + custom trend | 结构+趋势合一 |

## 注意事项
- 类别多（>10）优先 `bar` 并排或 `bar-negative` 横向
- 趋势对比用 `line` 更合适。
