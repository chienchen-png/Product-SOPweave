# 图表模板：waterfall（瀑布图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

展示数值从起点到终点的增减过程（差异桥接）。

## 典型场景
- 预算差异桥接：期初预算 → 各项调整 → 期末实际（D3）
- 利润桥：收入 → 成本 → 费用 → 净利
- 期初 → 期末 现金流变化分解

## 数据结构
```json
{
  "categories": ["期初预算", "收入增加", "成本上升", "费用节约", "期末实际"],
  "series": [
    {
      "name": "金额",
      "data": [
        { "value": 1000, "itemStyle": { "color": "gray" } },
        { "value": 150 },
        { "value": -80 },
        { "value": 30 },
        { "value": 1100, "itemStyle": { "color": "gray" } }
      ]
    }
  ]
}
```
- 首尾"总"节点灰色；中间增减节点正负着色（增=红/橙，减=绿/蓝）
- ECharts waterfall 通过堆叠 + 透明占位实现，模板内部处理

## 选型建议
- 差异分解 → waterfall
- 时间趋势 → line
- 类别对比 → bar

## 变体清单（P5-②，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `waterfall` / `waterfall-simple` | 桥接瀑布（默认） | 期初→调整→期末（D3/E1） |
| `waterfall-bar` | 紧凑瀑布 | 更多增减项时（绿增红减） |

> 借鉴官方示例：bar-waterfall（堆叠 + 透明占位实现）。

## 注意事项
- 增减顺序按时间/逻辑排列
- 首尾必须明确标注（起点/终点）
