# 图表模板：gauge（仪表盘）

> **复杂度档位：L1 简单**（P6-①：单/双变量平面图，直观快速）

## 用途
单个 KPI 达成度展示（指针 + 区间）。

## 典型场景
- 预算达成率
- 回款率
- 目标完成进度

## 数据结构
```json
{
  "series": [
    {
      "name": "达成率",
      "data": [
        { "value": 82, "name": "预算达成率" }
      ],
      "max": 100
    }
  ]
}
```
- value：当前值；max：量程上限
- 区间颜色（红/黄/绿）由模板内部按比例分段

## 选型建议
- 单个 KPI 达成 → gauge
- 多 KPI 对比 → radar / bar
- 趋势 → line

## 变体清单（P5-②，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `gauge` / `gauge-simple` | 进度仪表（默认） | 指针 + 进度弧 |
| `gauge-progress` | 大进度环 | 目标达成率（环形进度） |
| `gauge-stage` | 阶段仪表 | 红黄绿分段，KPI 预警 |

> 借鉴官方示例：gauge-progress / gauge-stage（分段色）。

## 注意事项
- 每次只展示 1-2 个仪表（过多无意义）
- value/max 量纲要一致
- 进阶模板，KPI 汇报场景使用
