# 图表模板：boxplot（箱线图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

展示数据分布：最小值、Q1、中位数、Q3、最大值、异常值。

## 典型场景
- 多组数据分布对比（如各部门费用分布）
- 月度指标离散度（G1）
- 异常值识别

## 数据结构
```json
{
  "categories": ["部门A", "部门B", "部门C"],
  "series": [
    {
      "name": "费用分布",
      "data": [
        [80, 95, 110, 130, 200],
        [60, 75, 90, 120, 160],
        "[..." ]
      ]
    }
  ]
}
```
- 每组 data 为 [min, Q1, median, Q3, max] 五数
- 分布数据需先在计算层算五数摘要

## 选型建议
- 分布对比 → boxplot
- 单组分布形态 → histogram
- 均值对比 → bar（带误差条）

## 变体清单（P5-②，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `boxplot` / `boxplot-simple` | 单系列箱线（默认） | 一组分布（五数摘要） |
| `boxplot-multi` | 多系列箱线 | 多组分布对比（按系列名分组） |

> 借鉴官方示例：boxplot-multi（多系列）。

## 注意事项
- 模板接收的是五数摘要（不是原始数据）
- 异常值点可经 option_overrides 加 scatter 叠加
