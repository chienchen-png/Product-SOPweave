# 图表模板：waterfall3d（3D 瀑布图 / 3D 指标对比图）

> **复杂度档位：L3 复杂**（2026-08-23 新增；v6.9 起**由 Python(mplot3d) 生成 PNG**）
> 复刻「财务指标对比.py」：x=年份、y=财务指标、z=数值，每个指标在 3D 空间并排一条折线+半透明填充面，从前到后蓝色渐变。
> **AI 无需介入绘图**：将 template="waterfall3d" 与本页数据结构写入图表 JSON 文件，再调用 `generate_chart(chart_file="图表文件相对路径")` 提交数据，前端识别该模板后自动调
> `/api/apps/finmod/py-chart` 由 Python 渲染 PNG（不再走 echarts-gl/WebGL）。

## 用途
多个财务指标在不同年份的**并排 3D 对比**（立体折线填充面），直观看出各指标随时间的升降趋势与相对大小。区别于 2D waterfall（桥接增减），这里把指标**并列排布**在 y 轴。

## 典型场景
- 财务指标连续多年对比（照明/IoT 利润贡献率、ROE、周转率等，D2 财务比率）
- 多产品线/多业务 × 年度 × 指标值
- 杜邦体系多比率逐年对比

## 数据结构
```json
{
  "xCategories": ["2021年", "2022年", "2023年"],
  "yCategories": ["照明利润贡献率", "IoT利润贡献率", "总资产周转率", "加权净资产收益率", "总资产报酬率"],
  "xAxisName": "时间（年）",
  "yAxisName": "财务指标",
  "zAxisName": "数值（%）",
  "color_scheme": "blues",
  "series": [
    { "name": "指标对比", "data": [
      [0, 0, 54.44], [1, 0, 48.97], [2, 0, 47.83],
      [0, 1, 22.37], [1, 1, 27.30], [2, 1, 25.37],
      [0, 2, 33.25], [1, 2, 33.25], [2, 2, 28.50],
      [0, 3, 13.13], [1, 3, 15.91], [2, 3, 9.33],
      [0, 4, 6.19],  [1, 4, 8.71],  [2, 4, 5.35]
    ]}
  ]
}
```
- xCategories / yCategories：两个维度类别（x=年份、y=指标）
- series[0].data：每行 `[xIdx, yIdx, zVal]`（xIdx=年份下标，yIdx=指标下标）
- color_scheme：配色（默认 blues，按 y 维度从前到后深→浅蓝，复刻 matplotlib Blues）

## 选型建议
- 多指标 × 多年份对比 → waterfall3d（立体并排，视觉冲击强）
- 单指标多年趋势 → line（平面足够）
- 单年份多指标占比 → pie / bar
- 双类别 × 数值 → bar3d（柱状立体）

## 注意事项
- 指标 ≤ 8 个、年份 ≥ 3 个（太少立体感弱，太多视觉混乱）
- **由 Python(mplot3d) 渲染 PNG**：不支持矢量导出（仅 PNG）、不支持拖拽旋转/缩放交互
- **图内不含数据大标题**（容器标题栏已展示表名）；坐标轴标签（时间（年）/财务指标/数值（%））保留
- 数值标注在 3D 空间可能被遮挡（小图上可不开 label）
- 数据格式与 echarts-gl 版完全一致，AI 侧无需感知底层渲染差异
