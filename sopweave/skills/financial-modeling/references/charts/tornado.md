# 图表模板：tornado（龙卷风图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

按对结果的影响大小排序展示各变量敏感性（E3），识别高风险变量。

## 典型场景
- 项目 NPV 敏感性排序
- 利润驱动因素重要度
- CVP 变量敏感度

## 数据结构
```json
{
  "categories": ["销量", "单价", "单位变动成本", "固定成本", "折现率"],
  "series": [
    { "name": "悲观(-15%)", "data": [-35, -28, 22, 15, -12] },
    { "name": "乐观(+15%)", "data": [35, 28, -22, -15, 12] }
  ]
}
```
- categories：变量名（按影响幅度从大到小排序）
- 悲观/乐观两系列：对结果的偏离幅度（±）
- 每变量横条 = [悲观影响, 乐观影响]

## 选型建议
- 敏感性排序 → tornado（最直观）
- 双变量网格 → heatmap
- 情景对比 → bar

## 注意事项
- 排序：影响大的在上（类别顺序 = 幅度降序）
- 数据来自 analyze_dataset（request.kind="sensitivity"）的 one_way 输出
- 正负表示方向（如成本上升 → NPV 下降）
