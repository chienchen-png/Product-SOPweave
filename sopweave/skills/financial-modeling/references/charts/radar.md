# 图表模板：radar（雷达图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

多维指标对比（维度 3-8 个），展示整体均衡度。

## 典型场景
- 财务五维比率对比（D2）：流动性/偿债/盈利/营运/发展
- 杜邦三要素对比（D1）
- 多部门 KPI 对比

## 数据结构
```json
{
  "indicators": [
    { "name": "流动性", "max": 100 },
    { "name": "偿债", "max": 100 },
    { "name": "盈利", "max": 100 },
    { "name": "营运", "max": 100 },
    { "name": "发展", "max": 100 }
  ],
  "series": [
    { "name": "本公司", "data": [{ "value": [78, 65, 82, 70, 60] }] },
    { "name": "行业均值", "data": [{ "value": [70, 70, 70, 70, 70] }] }
  ]
}
```
- indicators：各维度名 + max（雷达轴范围）
- series 每项 data[0].value：各维度得分（须归一化到同一量纲！）

## 选型建议
- 多维均衡对比 → radar
- 维度 > 8 个雷达难读 → 改用 bar
- 单维趋势 → line

## 变体清单（P5-②，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `radar` / `radar-simple` | 基础雷达（默认） | 单/多系列多维指标 |
| `radar-multi` | 多系列雷达 | 杜邦/同业对比（面积分层更明显） |

> 借鉴官方示例：radar / radar-multiple（多系列）。

## 注意事项
- **必须归一化**：各维度量纲不同（比率/次数/倍数）需先转标准分
- 2-4 个系列对比最佳；过多重叠难读
