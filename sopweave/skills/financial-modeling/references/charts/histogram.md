# 图表模板：histogram（直方图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

展示单变量数值分布形态（区间频数）。

## 典型场景
- 金额/比率分布形态（G1）
- 数据偏态/峰态直观判断
- 定价区间分布

## 数据结构
```json
{
  "categories": ["0-50", "50-100", "100-150", "150-200", "200+"],
  "series": [
    { "name": "频数", "data": [12, 30, 25, 10, 4] }
  ]
}
```
- categories：分箱区间标签
- data：各区间的观测频数（或频率）
- 分箱由计算层完成（如 pandas cut / hist）

## 选型建议
- 单变量分布 → histogram
- 多组分布对比 → boxplot
- 占比结构 → pie

## 注意事项
- 分箱数 5-15 个为宜（过多锯齿、过少失真）
- 区间边界要清晰标注
