# 图表模板：parallel（平行坐标图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

多维实体对比——每个实体一条折线穿过各维度坐标轴，适合多个公司的多指标横向对比。

## 典型场景
- 多家公司的营收/利润率/周转率三维对比
- 多个产品的价格/成本/毛利/销量四维对比
- 分支机构多指标体检

## 数据结构
```json
{
  "dimensions": [
    { "name": "营收(万)", "min": 0, "max": 1000 },
    { "name": "利润率(%)", "min": 0, "max": 100 },
    { "name": "周转率(次)" }
  ],
  "series": [
    { "name": "公司对比", "data": [
      [800, 15, 1.2],
      [1200, 20, 1.5]
    ]}
  ]
}
```
- dimensions：每列名称 + 可选 min/max
- series[0].data：每行一条折线（值顺序对应 dimensions）

## 变体清单（P5-③，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `parallel` | 平行坐标（默认） | 多维实体对比 |

> 借鉴官方示例：parallel-simple / parallel-nutrients。

## 选型建议
- 维度 ≥ 3 且要对比多个实体 → parallel
- 维度 = 2 → scatter 更直观
- 维度多但只看两个核心维度 → 双轴 scatter

## 注意事项
- 实体（行）≤ 30；维度 ≤ 8
- 维度单位不同时建议归一化或注明
