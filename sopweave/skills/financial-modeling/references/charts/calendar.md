# 图表模板：calendar（日历热力图）

## 用途

> **复杂度档位：L2 中等**（P6-①：多维变量 + 色彩/大小编码，财务最常用）

按日期维度展示数值分布（每天一格、颜色深浅表示大小），适合每日回款/支出/任务强度。

## 典型场景
- 每日回款金额热力（F1 现金周期）
- 每日费用/支出分布
- 每日销售/开单强度（全年日历）

## 数据结构
```json
{
  "categories": ["2025-01-01", "2025-12-31"],
  "series": [
    { "name": "回款", "data": [
      ["2025-01-05", 1200],
      ["2025-01-06", 800]
    ]}
  ]
}
```
- categories 可选：`[起始日, 结束日]` 兜底日历范围（或用 data.calendarRange）
- series[0].data：`["YYYY-MM-DD", 数值]` 每天一条

## 变体清单（P5-③，template 传 `类型-变体` 名）

| 变体 | 图表 | 选型 |
|------|------|------|
| `calendar` / `calendar-simple` | 单年日历（默认） | 一年内每日热力 |
| `calendar-year` | 多年日历 | 跨年上下排列对比 |

> 借鉴官方示例：calendar-heatmap / calendar-month。

## 选型建议
- 想看全年每日分布 → calendar
- 跨年对比（如 2024 vs 2025）→ calendar-year
- 只关心月份粒度 → line/bar 更合适

## 注意事项
- 数据 ≤ 500 点；日期格式必须 `YYYY-MM-DD`
- 范围超过 1 年用 calendar-year（多年上下排列）
