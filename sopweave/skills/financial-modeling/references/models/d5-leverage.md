# D5 经营/财务/总杠杆

## 目的
度量固定成本（经营杠杆）与固定融资成本（财务杠杆）对利润波动的放大作用。

## 关键公式
$$\text{经营杠杆系数} DOL = \frac{\text{边际贡献}}{\text{息税前利润}} = \frac{Q(P-v)}{Q(P-v)-F}$$

$$\text{财务杠杆系数} DFL = \frac{\text{息税前利润}}{\text{税前利润}} = \frac{EBIT}{EBIT - I}$$

$$\text{总杠杆系数} DTL = DOL \times DFL$$

## 变量含义
| 变量 | 含义 | 单位 |
|------|------|------|
| DOL | 经营杠杆系数 | 倍 |
| DFL | 财务杠杆系数 | 倍 |
| DTL | 总杠杆系数 | 倍 |
| EBIT | 息税前利润 | 元 |
| I | 利息费用 | 元 |
| F | 固定成本 | 元 |
| 边际贡献 | Q(P−v) | 元 |

## 适用场景
- 盈利波动风险评估
- 资本结构调整决策
- 收入变动对利润的影响预测

## 注意事项
- 用 query_dataset 取得输入，再由 run_process 按本页公式计算杠杆系数
- 杠杆越高，收入小变动引起利润大波动（双刃剑）
- DFL 高说明利息负担重、偿债压力大
