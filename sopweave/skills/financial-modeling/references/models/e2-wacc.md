# E2 WACC 估算

## 目的
加权平均资本成本：股权与债务成本的加权，作为折现率与资本预算基准。

## 关键公式
$$WACC = w_e \times r_e + w_d \times r_d \times (1 - T)$$

$$w_e = \frac{E}{E + D}, \quad w_d = \frac{D}{E + D}$$

## 变量含义
| 变量 | 含义 | 单位 |
|------|------|------|
| r_e | 权益成本（可用 CAPM：r_f + β×市场风险溢价） | % |
| r_d | 债务成本（借款利率） | % |
| T | 所得税率 | % |
| E | 股权市值 | 元 |
| D | 债务市值 | 元 |
| w_e / w_d | 权重 | % |

## 适用场景
- 项目折现率基准
- 资本结构优化
- 估值与 DCF 输入

## 注意事项
- 用 run_process 按本页 WACC 公式计算，明确输入 r_e/r_d/T/E/D 与单位；结果写为独立产物
- 债务成本税后化 ×(1−T)（利息抵税）
- 公司内部可简化：用平均借款利率近似 r_d
