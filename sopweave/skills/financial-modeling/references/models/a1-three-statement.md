# A1 三表联动模型

## 目的

把利润表、资产负债表、现金流量表三张报表动态勾稽连接：一组假设驱动三表联动变化，是最基础、最重要的财务模型地基。

## 核心勾稽关系

- 利润表净利润 → 资产负债表（留存收益增加）+ 现金流量表（经营活动起点）
- 资产负债表资产 = 负债 + 所有者权益（恒等式）
- 现金流量表期末现金 = 期初现金 + 经营/投资/筹资净流量

## 关键公式

$$
\text{净利润} = \text{营业收入} - \text{营业成本} - \text{费用} - \text{税金}
$$

$$
\text{期末留存收益} = \text{期初留存收益} + \text{净利润} - \text{股利}
$$

$$
\text{期末现金} = \text{期初现金} + \text{经营活动净流量} + \text{投资活动净流量} + \text{筹资活动净流量}
$$

$$
\text{资产} = \text{负债} + \text{所有者权益}
$$

## 变量含义

| 变量           | 含义           | 单位 |
| -------------- | -------------- | ---- |
| 净利润         | 利润表底线     | 元   |
| 留存收益       | 未分配利润累计 | 元   |
| 股利           | 当期分配       | 元   |
| 经营活动净流量 | 经营产生现金   | 元   |
| 投资活动净流量 | 投资产生现金   | 元   |
| 筹资活动净流量 | 融资产生现金   | 元   |

## 适用场景

- 全面财务预测、企业估值的前置模型
- 检验三表数据一致性（勾稽校验）
- 支持敏感性/情景分析的基准框架

## 注意事项

- 折旧摊销要同时影响利润表费用与现金流量表（加回）
- 营运资金变动（应收/应付/存货）是经营活动现金流的关键调节项
- 三表必须勾稽平衡，否则模型无效
