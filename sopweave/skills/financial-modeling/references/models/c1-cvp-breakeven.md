# C1 本量利（CVP）/盈亏平衡模型

## 目的
分析销量、单价、成本与利润的关系，求盈亏平衡点、保利点、安全边际与经营杠杆。

## 关键公式
$$\text{利润} = (\text{单价} P - \text{单位变动成本} v) \times \text{销量} Q - \text{固定成本} F$$

$$\text{盈亏平衡销量} Q^* = \frac{F}{P - v}$$

$$\text{盈亏平衡收入} = \frac{F}{\text{边际贡献率}}$$

$$\text{安全边际} = \text{实际销量} - \text{盈亏平衡销量}$$

$$\text{经营杠杆系数} DOL = \frac{Q(P - v)}{Q(P - v) - F}$$

## 变量含义
| 变量 | 含义 | 单位 |
|------|------|------|
| P | 单价 | 元/件 |
| v | 单位变动成本 | 元/件 |
| F | 固定成本 | 元 |
| Q | 销量 | 件 |
| Q* | 保本销量 | 件 |
| 边际贡献率 | (P−v)/P | % |
| DOL | 经营杠杆系数 | - |

## 适用场景
- 保本点测算
- 定价与促销决策
- 固定成本扩张风险分析

## 注意事项
- 调用 analyze_dataset，request.kind="sensitivity"、model_type="cvp"，从结果读取 break_even
- 边际贡献 = P − v，是 CVP 的核心概念
- 线性假设：单价与变动成本在分析区间内不变
