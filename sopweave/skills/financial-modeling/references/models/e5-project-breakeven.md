# E5 项目盈亏平衡

## 目的
求使 NPV = 0（或利润 = 0）的关键变量值，如保本销量、保本单价。

## 关键公式
$$\text{使} NPV=0 \text{的销量}：Q^*(NPV=0)$$

$$\text{保本单价}：P^* = v + \frac{F}{Q}$$

$$\text{保本销量}：Q^* = \frac{F}{P - v} \quad (\text{不含折旧}/\text{税时})$$

## 变量含义
| 变量 | 含义 | 单位 |
|------|------|------|
| Q* | 保本销量 | 件 |
| P* | 保本单价 | 元/件 |
| v | 单位变动成本 | 元/件 |
| F | 固定成本（含折旧） | 元 |

## 适用场景
- 项目可行性阈值判断
- 定价底线
- 规模决策

## 注意事项
- 经营级 CVP 使用 analyze_dataset（request.kind="sensitivity"、model_type="cvp"）；项目 NPV 阈值由 run_process 对只读快照执行 Python 二分求根，先明确变量、搜索区间和收敛容差，并检查根是否存在
- 项目级盈亏平衡用 NPV=0 口径（含时间价值）
- 与 C1 经营级盈亏平衡区分：项目级含投资与折现
