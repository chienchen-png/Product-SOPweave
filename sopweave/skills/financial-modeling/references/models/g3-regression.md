# G3 回归分析

## 目的
用自变量预测/解释因变量，量化影响大小与显著性（公司内部经营变量建模）。

## 关键公式
$$\text{一元}：y = a + b x + \varepsilon$$

$$\text{多元}：y = a + b_1 x_1 + b_2 x_2 + \cdots + b_k x_k + \varepsilon$$

$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$$

## 变量含义
| 变量 | 含义 | 单位 |
|------|------|------|
| y | 因变量（如收入） | 元 |
| x_i | 自变量（如促销费） | 元 |
| a | 截距 | - |
| b_i | 回归系数（x_i 变化 1 单位 y 的变化） | - |
| R² | 拟合优度（0~1） | - |
| p 值 | 系数显著性（<0.05 显著） | - |
| ε | 残差 | - |

## 适用场景
- 收入/成本驱动因素量化
- 预测模型（结合时间趋势）
- 弹性分析（价格弹性）

## 注意事项
- 用 analyze_dataset，request.kind="regression"，指定 x_columns/y_column；内核使用一元 scipy.linregress 或多元 lstsq
- 散点图 + 回归线（scatter）；残差图检查线性假设
- 多元注意多重共线性；报告 R² 与系数显著性
- **相关 ≠ 因果**：报告中必须注明
