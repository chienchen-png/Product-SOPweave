# 第三方组件与许可

Python 依赖按完整锁收集，npm 依赖按已安装的 package-lock 收集；原始许可、NOTICE 和包元数据保留在 `third-party`。

Pandoc 作为独立进程调用，由用户从官方发行版单独安装；其 GPL 与第三方版权原文见 [Pandoc notices](third-party/pandoc/COPYRIGHT.txt)。上游源码获取方式及 GPL 条款见该文件与 COPYING.rtf。项目自身授权不替代第三方条款。
